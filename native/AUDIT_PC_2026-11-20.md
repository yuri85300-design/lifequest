## Détails reproductibles

- **150 tests isolés** : chaque carte a été ajoutée à une partie factice puis
  son entrée en jeu (ou appel de Légende) a été tentée.
- **22 500 tests par paires** : chaque couple ordonné de cartes a été joué
  avec les deux camps configurés, puis les invariants UID, propriétaire des
  cartes dans les decks et unicité des dés ont été contrôlés.
- **1 000 matchs** : scénarios multi-decks, graines fixées, sièges alternés,
  politique FastPolicy. Aucune victoire artificielle due au plafond de 100
  tours : le moteur retourne alors le statut `incomplete` (et les tests
  l'auraient signalé).
- **5 tests ciblés** : coût minimum réduit, jeu gratuit, répartition par
  propriétaire, disparition des états temporaires, retour au deck rival.
- **IA avancée** : une partie Tactique+ (14 tours) et une partie NIGHTMARE (13 tours) se sont terminées sans exception ; l'environnement V8 de test nécessitait une fonction de copie structurée compatible avec le format JSON de l'état. Échantillon trop faible pour affirmer une supériorité statistique.
- **Worker** : un état de jeu synthétique a été envoyé à `ai-worker.js`,
  qui a signalé `ready` puis retourné un coup légal.
- **Navigation PC** : suite Playwright ajoutée en
  `native/pc_smoke.spec.cjs`, pour affichages desktop + écran mobile.
  Les résultats sont en attente d'une exécution Chromium complète.

### Limites

Les 22 500 scénarios prouvent que les fonctions invoquées n'ont pas violé
les invariants techniques contrôlés. Ils ne démontrent ni la couverture des
branches cachées, ni les conditions d'action, ni les choix simultanés, ni la
conformité des effets individuels à leurs textes anglais.

Le référentiel officiel en ligne indique une actualisation le
**17 novembre 2026 avec 74 changements**. Le contenu de cet audit n'est pas
une comparaison exhaustive de ces modifications et des 150 cartes.

Le verrou `NIGHTMARE_TRAINING_CERTIFIED = false` doit rester en place
jusqu'à la certification officielle. Le compteur et les mentions
trompeuses d'entraînement « validé » ont été corrigés sur l'interface.

## Commandes de reproduction sur PC

```sh
node native/extract_engine.cjs
node native/audit_220.cjs
npm install --no-save @playwright/test@1.56.1
npx playwright install chromium
npx playwright test --config native/playwright.config.cjs
```

GitHub Actions : `prime-audit.yml` et `pc-smoke.yml`. Leur exécution et
leurs journaux doivent être contrôlés séparément ; les résultats ci-dessus
proviennent de l'audit V8 déjà exécuté, pas d'un statut CI prétendument vert.

## Correctifs réalisés

- Suppression des chiffres de duels artificiellement majorés dans NIGHTMARE.
- Remplacement de formulations de certification non justifiées.
- Ajout de tests navigateur desktop / mobile dans le dépôt (dont ouverture du duel et conservation du défi).
- Correction des sauvegardes de decks malformés : elles signalent désormais les cartes inconnues au lieu de faire planter la bibliothèque.
- Après correction du moteur, les **1 000 matchs IA/IA** ont été relancés et ont conservé le même bilan : 1 000 terminés, 0 incomplet, 0 action illégale.
- Conservation de la séparation entre validation technique et officielle.
